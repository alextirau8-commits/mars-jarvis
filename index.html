How do I get a Client ID?
  1. Open console.cloud.google.com and create a project.
  2. Enable the Google Drive API.
  3. Set up the OAuth consent screen and add yourself as a test user.
  4. Credentials → Create OAuth client ID → Web application.
  5. Add this page’s address (for example http://localhost:8000) under Authorized JavaScript origins.
  6. Paste the Client ID above.
